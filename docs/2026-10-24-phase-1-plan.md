> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兩種語言都能從地圖進 T3、T4 主題頁，切換語言停在同一頁；全站設計稿 6.4 與 9.2 的檢查全部通過。

**Architecture:** 靜態網站。每個已上線的路徑在建置時用 React 預先產生 HTML（Vite `ssrLoadModule`），頁與頁之間是一般的 `<a href>` 整頁載入，不用前端路由；瀏覽器端 hydrate 只為了語言選單、記住語言選擇與目錄的顯示／隱藏按鈕；根路徑沒有頁面，只用 `<head>` 裡的腳本轉址（2026-10-26 改）。段落結構（id、書中標題、頁碼、評級）由產生器從筆記輸出成 `src/content/sections.ts`；文字依語言放在 `src/content/<lang>/`，元件透過一個 `Content` 物件取得所有文字。

**Tech Stack:** Node ≥ 22.13、pnpm、Vite 5.4.21、React 18.3.1、TypeScript 5.7.3、vitest 2.1.9、Playwright 1.63.0、axe-core 4.10.2。

**Spec:** `docs/2026-10-24-site-design.md`（全站設計稿，以下稱「設計稿」）。每段筆記的去處見 `docs/content-index.md`。D1 設計稿 `docs/2026-10-24-d1-timeout-retry-design.md` 本階段只借用它的情境與用詞。
